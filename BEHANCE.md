Instruções para adicionar o site no Behance
=========================================

- URL pública (provável): https://Toxizada.github.io/appledesign.github.io/

1) Snippet de embed (HTML)

```html
<iframe src="https://Toxizada.github.io/appledesign.github.io/" width="1200" height="800" frameborder="0" allowfullscreen></iframe>
```

2) Passos rápidos no Behance
- Crie um novo projeto (Create a Project).
- Clique em `+` e escolha `Embed` (ou `Add` -> `Embed`).
- Cole a URL pública ou o snippet acima.
- Se o Behance não aceitar o embed, adicione uma imagem/screenshot do site e coloque a URL pública no campo "Project URL".

3) Como gerar uma screenshot para o projeto (opcional)
- Abra a URL pública e tire uma captura de tela manualmente.
- Ou use Chromium/Chrome headless (se instalado):

```bash
google-chrome --headless --screenshot=preview.png --window-size=1200,800 "https://Toxizada.github.io/appledesign.github.io/"
```

4) Observações
- O GitHub Pages pode demorar alguns minutos após o push/Actions para ficar disponível.
- Não tenho acesso à sua conta Behance — preciso que você cole o embed/public link no editor do Behance ou me autorize a fazê-lo.
